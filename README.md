## 📋 Descripción

Sistema integral de gestión logística desarrollado exclusivamente para **Agro Industrias Marsa**. Esta plataforma permite la administración completa de operaciones internas.

El sistema ha sido diseñado específicamente para adaptarse a los procesos y necesidades operativas de Agro Industrias Marsa.

## 🛠️ Tecnologías Implementadas

### Backend
- **PHP 7.4+**: Lenguaje principal del servidor
- **MySQL**: Sistema de gestión de base de datos
- **Arquitectura MVC**: Modelo-Vista-Controlador para organización del código

### Frontend
- **JavaScript ES6+**: Funcionalidad del lado del cliente
- **HTML5/CSS3**: Estructura y diseño de la interfaz
- **DataTables**: Tablas interactivas y búsqueda avanzada
- **AJAX**: Comunicación asíncrona con el servidor

### Librerías y Dependencias
- **PHPSpreadsheet**: Generación de archivos Excel
- **FPDF/tFPDF**: Generación de documentos PDF
- **Picqer Barcode Generator**: Generación de códigos de barras
- **HTML Purifier**: Sanitización de entradas HTML

## 🔒 Seguridad

El sistema implementa múltiples capas de seguridad:

- ✅ **Encriptación de contraseñas**: Hash seguro de credenciales
- ✅ **Protección contra SQL Injection**: Uso de prepared statements
- ✅ **Validación de entradas**: Sanitización de todos los datos de usuario
- ✅ **Protección XSS**: Filtrado de contenido malicioso
- ✅ **Control de sesiones**: Gestión segura de autenticación
- ✅ **HTTPS Ready**: Compatible con comunicación encriptada SSL/TLS
- ✅ **Control de acceso**: Sistema de permisos por roles

## 👨‍💻 Módulos del Sistema

1. **Almacén**: Control de stock y movimientos
2. **Productos**: Catálogo de productos
3. **Clientes**: Base de datos de clientes
4. **Lotes**: Seguimiento de lotes de producción
5. **Ingresos**: Registro de entradas al almacén
6. **Notas de Pedido**: Gestión de pedidos
7. **Personal**: Administración de usuarios
8. **Reportes**: Generación de informes Excel y PDF
